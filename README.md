## 🚀 Quick Start (Template)

### Prerequisites

- **Python 3.10+** installed on your system
- **OpenWeather API Key** or similar weather data provider key

### Installation

```powershell
# Step 1: Clone the repository
git clone https://github.com/Aumnamaha/Weather-App.git
cd Weather-App

# Step 2: Activate virtual environment
& "C:\Users\Aum Namaha\Documents\finalenv\Scripts\Activate.ps1"

# Step 3: Install dependencies (once requirements.txt is added)
# pip install -r requirements.txt

# Step 4: Set your API key
$env:WEATHER_API_KEY = "your-api-key-here"

# Step 5: Launch the application
# python main.py   # or: streamlit run app.py
```
